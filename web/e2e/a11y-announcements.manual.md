# Ручной чек-лист: озвучивание стрима (W2)

Автотесты проверяют **разметку** (`axe`) и **правила** канала (юнит-тесты
`tests/unit/stream-a11y.test.ts`, `tests/unit/live-announcer.test.tsx`). Поведение
конкретной пары «браузер + скринридер» автоматизировать нельзя: очередь
объявлений, склейка быстрых изменений и «перечитывание» — это реализация
скринридера, а не DOM.

Чек-лист прогоняется вручную перед релизом изменений в стриме ответа
(VoiceOver на macOS/Safari или NVDA + Firefox/Chrome).

## Подготовка

1. `cd web && npm run dev`, открыть `http://localhost:5173/standalone.html`.
2. Включить скринридер, выключить озвучивание по клику мышью.
3. Бэкенд должен отдавать типизированный стрим (`block_delta`); если его нет,
   второй сценарий всё равно проверяется на markdown-пути.

## Сценарий 1 — длинный ответ (5+ абзацев)

| Шаг                     | Ожидаемо                                                          |
| ----------------------- | ----------------------------------------------------------------- |
| Отправить запрос        | Один раз звучит фаза работы («Думаю…», затем смены фаз)           |
| Пошёл текст             | Слышны **закрытые абзацы по одному**, без повторов уже сказанного |
| Ответ завершился        | Одно объявление «Ответ готов.» — **без** перечитывания ответа     |
| Ход с `requires_review` | «Ответ готов. Требуется ваша проверка.»                           |
| Ошибка стрима           | «Ошибка: …» — не тишина и не старое «ответ готов»                 |

Провал: ответ читается дважды; слышны обрывки фраз; после финала тишина;
объявление приходит на каждый токен.

## Сценарий 2 — ответ с таблицей и списком

| Шаг                     | Ожидаемо                                                                |
| ----------------------- | ----------------------------------------------------------------------- |
| Таблица закрылась       | «Таблица: столбцов N, строк M. <заголовки>» — **без** содержимого ячеек |
| Список закрылся         | Одно объявление: количество, до 5 пунктов, дальше «и ещё N»             |
| Блок кода закрылся      | «Блок кода, язык X, строк: N»                                           |
| Разделитель (`divider`) | Ничего не звучит                                                        |

## Что НЕ проверяется автоматикой (осознанно)

- Порядок объявлений при экстремально быстром стриме: канал склеивает блоки
  одного тика в одно объявление, поэтому часть абзацев может прозвучать слитно.
  Терять текст при этом нельзя — это и проверяют юнит-тесты.
- Прерывание речи пользователем (Ctrl / «стоп» скринридера).
- HITL-карточки: у них свой `aria-live="polite"`, независимый от канала стрима.
